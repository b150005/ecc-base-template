# Payload manifest — files/globs allowed on the main branch.
#
# One entry per line. Lines starting with '#' are comments;
# blank lines are ignored. Globs use ** for recursive match
# and * for single-segment match.
#
# Maintained manually by template maintainers on develop.
# Enforced by .github/workflows/payload-manifest-check.yml
# (runs on pull_request to main).
#
# NOTE: main carries 0 fork-facing CI workflows by design (per ADR-026
# amendment 2026-05-21). The .github/workflows/.gitkeep entry preserves
# the folder so forks remember to add their own CI if desired. The
# single .github/workflows/payload-manifest-check.yml is the template-
# internal boundary-enforcement workflow — it must live on main because
# GitHub Actions resolves pull_request workflows from the PR head ref;
# forks without a develop branch graceful-skip the check. The
# .claude/meta/scripts/init.sh entry is the fork-facing initializer
# (the only file kept under .claude/meta/scripts/).
